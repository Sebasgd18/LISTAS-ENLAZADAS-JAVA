# LISTAS-ENLAZADAS-JAVA
Linked Lists Manager — Java NetBeans

Sistema desarrollado en Java utilizando NetBeans IDE para la implementación y simulación de Listas Enlazadas mediante estructuras dinámicas de datos.

El proyecto permite crear, insertar, eliminar, buscar y recorrer nodos de manera eficiente, demostrando el funcionamiento interno de las listas enlazadas en programación.

Características
Implementación de listas enlazadas simples
Inserción de nodos
Eliminación de nodos
Búsqueda de elementos
Recorrido completo de la lista
Gestión dinámica de memoria
Interfaz amigable en Java
Simulación visual de estructuras dinámicas
Tipos de Listas Implementadas
Lista Enlazada Simple
Lista Doblemente Enlazada
Lista Circular
Lista Circular Doble
Tecnologías Utilizadas
Java
NetBeans IDE
Programación Orientada a Objetos
Estructuras de Datos
Java Swing
Funcionamiento

Las listas enlazadas permiten almacenar datos mediante nodos conectados entre sí usando referencias dinámicas.

Cada nodo contiene:

Información
Referencia al siguiente nodo
(Opcional) referencia al nodo anterior

El sistema permite manipular los nodos en tiempo real simulando el comportamiento de estructuras dinámicas utilizadas en sistemas operativos, bases de datos y software empresarial.
